# ⚔ Warlords II — MVP Prototype (standalone)

Пошаговая фэнтезийная стратегия в духе Warlords II. Полностью автономная версия:
один файл `index.html` (~590 КБ) — движок Three.js, игровая логика, звук и интерфейс
вшиты внутрь. **Интернет и установка чего-либо не требуются.**

## Запуск

- **Windows / macOS / Linux:** двойной клик по `index.html` — игра откроется в браузере
  (Chrome, Edge, Firefox, Safari — любая современная версия).
- Либо через локальный сервер (не обязательно):
  `python -m http.server 8000` → http://localhost:8000/index.html

## Как играть

- **Цель:** захватить все города на карте.
- **ЛКМ** — выбрать отряд / идти / атаковать (белые клетки — зона хода).
- **ПКМ (зажать) или WASD** — камера, **колесо** — зум, **Esc** — отмена, **пробел** — конец хода.
- Стоимость хода: равнина 1, лес 2, горы 3. Местность даёт защиту: лес +25%, горы +50%.
- В своём городе отряд лечится (+4 HP/ход) и получает +25% защиты; город нанимает отряды (раз в 2 хода).
- Захват города: войдите отрядом в город без защитников.
- ИИ сам нанимает отряды и идёт на ваши города — защищайтесь!

## Карта по seed

Поле «Seed карты»: введите число и нажмите ▶ — карта сгенерируется детерминированно
(одинаковый seed → одинаковая карта). Пустое поле — случайная карта.

## Сохранения

Кнопка «Сохр.» пишет партию в localStorage браузера, «Загр.» восстанавливает.
Каждый раунд автосохраняется. Внимание: сейвы привязаны к браузеру и домену/пути файла.

## Пересборка из исходников

Исходники (Next.js-проект) лежат в `warlords2-nextjs-src.zip`. Ядро игры — чистый
TypeScript в `src/lib/game/`, ванильная обвязка — `src/standalone/`. Пересборка:

```bash
bun install          # или npm install
bash scripts/build-standalone.sh
# → download/warlords2-standalone/index.html
```

Полноценная веб-версия (тот же движок + React-интерфейс): `bun run dev` → http://localhost:3000
