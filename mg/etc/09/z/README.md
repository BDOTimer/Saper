# ПЕПЕЛЬНЫЙ ГОРОД — процедурный FPS (Three.js)

Первое лицо, полностью **процедурно генерируемый** разрушенный город: руины зданий,
воронки, брошенные машины, сухие деревья, трава, мусор и пыль в воздухе.
Ни одного внешнего ассета — все текстуры рисуются кодом на canvas, все модели
строятся из примитивов при запуске. Один и тот же **seed** всегда даёт один и
тот же мир.

---

## Запуск

**Вариант 1 (обычный):** распакуйте архив и дважды щёлкните `index.html` —
игра работает локально через `file://` (Chrome / Edge / Firefox).

**Вариант 2 (если браузер строгий):** локальный сервер из папки игры:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

Требуется только WebGL + мышь/клавиатура. Всё остальное — оффлайн.

## Управление

| Клавиша | Действие |
|---|---|
| **WASD** | движение |
| **Shift** | бег (7.2 м/с против 4.2 м/с шага) |
| **Space** | прыжок (на груды обломков и низкие стены можно запрыгивать) |
| **Мышь** | обзор (pointer lock, клик по экрану) |
| **ЛКМ** | огонь |
| **ПКМ** | прицеливание (FOV ближе, разброс меньше) |
| **1 / 2** | винтовка / нож |
| **Колесо** | быстрая смена оружия |
| **Esc** | пауза / меню |
| **F3** | debug-панель: FPS, draw calls, коллайдеры |
| **R** | перегенерация мира со случайным seed |

## Seed

* Адресная строка: `index.html?seed=12345` — мир воспроизведётся один в один.
* Меню паузы: поле «Seed» + «Применить seed» / «Случайный».
* Детерминизм обеспечен позиционным ГПСЧ `rngAt(seed, x, z, tag)`:
  объект привязан к своим координатам, поэтому порядок и разбивка
  асинхронной генерации на кадры не влияют на результат.

## Конфигурация — `js/config.js`

| Параметр | Что меняет |
|---|---|
| `seed` | стартовый seed мира |
| `map.size / blockSize / roadWidth` | размер карты (м), сетка кварталов и дорог |
| `city.buildingDensity / parkChance / maxFloors` | плотность застройки, пустыри, высотность |
| `destruction` | 0..1 общая степень разрушения зданий |
| `craters.count / minR / maxR / maxDepth` | воронки от снарядов |
| `props.*` | количество камней, обломков, кирпичей, брёвен, деревьев, кустов, травы (`grassPerM2`, дальность `grassDist`), мусора, машин, фонарей |
| `light.*` | азимут/высота солнца, цвета, туман, exposure, лучи, пыль |
| `cascades[]` | каскады теней: дальность, размер карты теней, доля интенсивности |
| `player.*` | скорости, высота камеры, гравитация, прыжок, автошаг, FOV |
| `combat.playerDamagePercent` | урон за одно попадание врага (по умолчанию **20%**) |
| `combat.rifle` | винтовка: урон, множители хитзон, кулдаун, разброс, дальность, магазин (20) |
| `combat.knife` | нож: урон, кулдаун, дальность и сектор удара |
| `combat.pickups` | шанс/объём трофеев: патроны и аптечки с убитых |
| `combat.enemies.count / spawnMinDist / activationDist` | число врагов, мин. дистанция спавна, радиус пробуждения ИИ |
| `combat.enemies.types.*` | три типа: здоровье, вес спавна, дальность, разброс, кулдауны, время прицеливания |
| `quality.*` | pixelRatio, сегментация рельефа, вкл/выкл теней |

## Как устроена генерация

* **Шумы** (`js/noise.js`): Simplex 2D, Perlin 2D/3D, Voronoi (F1/F2 + id ячейки),
  fBm и ridged — всё от seed. Рельеф, «урбанистичность» кварталов,
  кластеры растительности и степень разрушений — на шумах.
* **Рельеф** (`js/terrain.js`): heightfield 256×256 (fBm), дороги «протаптывают»
  рельеф до нуля, воронки — чаша + вал; коллизия рельефа аналитическая
  (`heightAt(x,z)`), вершинные цвета земли задают закопчённость у воронок.
* **Кварталы** (`js/city.js`): сетка блоков/дорог; на каждый блок — позиционный
  ГПСЧ. Здание собирается из сегментов стен с «рваной» линией обрушения,
  плит перекрытий и груд обломков; геометрия сливается в 2 меша
  (фасад + бетон) — суммарно ~110 draw calls на всю сцену.
* **Пропсы** (`js/props.js`): модульные генераторы (камни, бетон, кирпичи, доски,
  арматура, брёвна, деревья, кусты, трава, мусор, машины, фонари).
  Всё на **GPU Instancing**; трава разбита на чанки 32 м с дистанционным
  culling'ом. Размещение через **claims-сетку** — объекты не пересекаются,
  спавн и перекрёстки свободны.
* **Коллизии** (`js/grid.js`, `js/player.js`): spatial grid статических AABB.
  Слои физики: `TERRAIN | BUILDING | PROP | DEBRIS | PLAYER`; игрок
  проверяется против BUILDING/PROP/DEBRIS, статика со статикой не
  сталкивается. Автошаг 0.55 м, вставание на коробки, гравитация, coyote-time.
* **Свет** (`js/lighting.js`): низкое тёплое солнце с **двумя каскадами теней**
  (PCFSoft, 70 м @2048 и 260 м @4096, привязка к текселю за игроком),
  hemisphere-заполнение (холодное небо / тёплая пыль), шейдерное небо с
  диском солнца, псевдообъёмные лучи в проёмах улиц, шейдерная пыль в
  воздухе, экспоненциальный туман. ACES tone mapping.
* **Асинхронность** (`js/generator.js`): генерация разбита на фазы и кадры
  (rAF) — экран загрузки показывает прогресс, браузер не фризит.
* **Звук** (`js/audio.js`): процедурный WebAudio — ветер (фильтрованный шум),
  шаги, приземления, редкие далёкие гулы, выстрелы трёх типов, удары ножа,
  попадания и смерть. Без аудиофайлов.

## Боевая система — `js/combat.js`, `js/weapons.js`, `js/enemies.js`

Всё инкапсулировано в классах ES6:

* **`Combat`** — боевая математика: аналитические лучи против AABB-коллайдеров
  (DDA-обход spatial grid), рельефа (марш по heightfield + бисекция), сфер
  (головы) и вертикальных цилиндров (капсулы тел). Хитзоны: голова ×2,
  тело ×1, ноги ×0.75. Пулы VFX без аллокаций: трассеры, вспышки выстрелов,
  частицы (искры бетона/пыль/кровь).
* **`Rifle`** — винтовка игрока: **20 патронов**, урон 34 (в голову ×2 —
  убийство с двух), hitscan с разбросом от бедра/при прицеливании (ПКМ),
  отдача, трассер из дула. **На пустом магазине автоматически достаётся нож**.
* **`Knife`** — конусный удар 2.3 м, урон 55, бесконечный.
* **`WeaponRig`** — процедурные вьюмодели на камере (винтовка с деревянным
  прикладом, нож), sway от мыши, bob при ходьбе, отдача, анимации смены
  оружия и замаха.
* **`Enemy` / `EnemyManager`** — три типа врагов, **процедурные тела** из
  примитивов (рост/оттенки/снаряжение рандомизированы от seed):

  | Тип | Оружие | Поведение |
  |---|---|---|
  | Штурмовик | дробовик, залп 7 дробин, 22 м | прижимается в упор |
  | Автоматчик | очередь по 3, 80 м | держит среднюю дистанцию |
  | Пистолетчик | одиночные, 45 м | юркий, частые выстрелы |

  Спавн — **за укрытиями**: менеджер собирает точки у стен, груд, камней,
  машин и деревьев из коллайдеров мира и ставит врагов так, чтобы укрытие
  было между ними и точкой появления игрока. ИИ-автомат: *укрытие → выглядывает
  вбок → прицеливание (0.4–0.9 с) → огонь → отходит за укрытие*; при опасности
  перебегает к новой точке (застревания обрабатываются сдвигом вбок).
  Проверка LOS — луч Combat с интервалом 0.16–0.28 с на врага; дальние враги
  (>140 м) спят. Каждое попадание в игрока снимает **20% здоровья**
  (`combat.playerDamagePercent`). Убитые враги падают, растворяются и с
  шансом 55%/22% оставляют **патроны (+6)** или **аптечку (+30 HP)**.
* Расклад врагов детерминирован: тот же seed → те же враги на тех же укрытиях.

## Структура

```
index.html          — разметка, стили UI, порядок скриптов
lib/three.min.js    — Three.js r149 (MIT, https://threejs.org)
js/config.js        — все параметры генерации
js/rng.js           — seeded RNG + позиционный rngAt
js/noise.js         — Simplex / Perlin / Voronoi + fBm
js/grid.js          — spatial grid коллайдеров и claims
js/textures.js      — процедурные canvas-текстуры и материалы
js/terrain.js       — рельеф, воронки, дороги, гарь
js/city.js          — кварталы и руины зданий
js/props.js         — все инстансированные объекты
js/lighting.js      — солнце, каскады теней, небо, лучи, пыль
js/combat.js        — класс Combat: лучи, хитзоны, пулы VFX
js/weapons.js       — Weapon/Rifle/Knife/WeaponRig + EnemyWeapon
js/enemies.js       — Enemy, EnemyManager, Pickup (3 типа врагов)
js/player.js        — FPS-контроллер, здоровье и вооружение игрока
js/audio.js         — процедурный звук
js/hud.js           — меню, боевой HUD, экран смерти
js/generator.js     — асинхронный оркестратор
js/main.js          — вход, игровой цикл
```

## Производительность

Целевые показатели (config по умолчанию, 256×256 м): ~110–160 draw calls,
~200 тыс. треугольников. Узкие места: `props.grassPerM2` (трава),
`quality.terrainSegments`, размер карт теней. На слабых машинах уменьшите
`grassPerM2` и `cascades[1].mapSize` до 2048.
