Навигация.

class Pers;
    - Хранит индексы Галактики и Звезды:
        indexGalaxy,
        indexStar,
        seedGalaxy,
        seedStar.

    - По этим индексам Pers получает сиды Галактики и Звезды от UniverseJS.
    - Эти данные являются базовыми для всей последующей генерации.
    - При перемещении по Вселенной эти данные обновляются в первую очередь.
    - Доступ к Pers осуществляется через экземпляр window.GAME...
    - Экземпляр класса window.GAME это синглетон.

    - Два метода ключевые:
        set indexGalaxy(i)
        set indexStar  (i)
    - По индексам вычисляются сиды.
    - Сиды не могут быть изменены извне - сиды только на чтение!
    - Вызваются в jump2Galaxy() и jump2Star()
    - indexGalaxy и indexStar выбираются из меню выбора Галактики и Звезды.
    - Выбор Галактики это отдельное меню.
    - Выбор Звезды    это отдельное меню.

Позиционирование объектов игры:
    - Star   : {0, 0, 0} всегда!
    - Ship   : {min: 5000, max: 20000} диапазон дистанции от Star.
    - Planets: {min: 1000, max:  3000} диапазон дистанции от Star.
    - Station: {min:  200, max:  600 } диапазон дистанции от Planet.
    - Enemies: {~} могут появлять в любом месте космоса,
        точки спавна:
        около Planet, Station
        около своей базов
        во время перелёта корабля.
