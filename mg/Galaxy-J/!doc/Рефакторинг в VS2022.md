Да, это **абсолютно возможно**. Полноценная Visual Studio (например, 2022) имеет мощнейший движок IntelliSense (базирующийся на TypeScript Language Service), который отлично работает с чистым JavaScript и HTML, предоставляя рефакторинг, поиск определений и автодополнение.

Главная проблема при открытии просто папки с файлами в Visual Studio заключается в том, что IDE может воспринимать каждый `.js` файл изолированно (как "Разные файлы" / Miscellaneous Files). Чтобы получить **ПОЛНОЦЕННЫЙ ПРОЕКТ**, где рефакторинг (например, переименование функции) работает сразу во всех файлах, нужно правильно инициализировать среду.

Вот пошаговая инструкция, как это сделать.

### Шаг 1. Выбор правильного типа проекта
Вам не обязательно создавать веб-приложение на C#. Для чистого JS+HTML лучше всего подходит шаблон **Node.js**, даже если вы не используете Node на бэкенде. Он дает правильную структуру проекта (`.njsproj`).

1. Откройте Visual Studio -> **Создать проект** (Create a new project).
2. В поиске введите **Node.js** и выберите шаблон **Пустой проект Node.js** (Blank Node.js Project) или **Базовое веб-приложение Node.js**.
3. Создайте проект.

*(Альтернатива: Если вам нужно запускать сайт через IIS Express, можно создать **Пустое веб-приложение ASP.NET**, но Node.js проект легче и быстрее для чистого фронтенда).*

### Шаг 2. Добавление ваших файлов
1. В **Обозревателе решений** (Solution Explorer) удалите стандартный `server.js` (если он не нужен).
2. Нажмите правой кнопкой мыши на имя проекта -> **Добавить** -> **Существующий элемент...** (Add -> Existing Item) или **Существующая папка**.
3. Выберите ваши `index.html` и все `*.js` файлы.

### Шаг 3. "Секретный ингредиент" для сквозного IntelliSense и Рефакторинга
Чтобы Visual Studio поняла, что все ваши `.js` файлы связаны между собой (и переменная из `utils.js` была видна в `main.js`), вам нужно добавить в корень проекта файл конфигурации **`jsconfig.json`**.

1. Правой кнопкой на проект -> **Добавить** -> **Создать элемент** (Add -> New Item).
2. Выберите **Файл конфигурации JavaScript** (JavaScript Configuration File) или просто создайте текстовый файл и назовите его `jsconfig.json`.
3. Вставьте туда следующий код:

```json
{
  "compilerOptions": {
    "target": "es6",
    "module": "es6", 
    "allowJs": true,
    "checkJs": false,
    "moduleResolution": "node",
    "baseUrl": ".",
    "paths": {
      "*": ["*", "*.js"]
    }
  },
  "include": [
    "**/*.js",
    "**/*.html"
  ],
  "exclude": [
    "node_modules"
  ]
}
```
*Примечание: Если вы используете старые скрипты без `import/export`, а просто подключаете их через `<script>` в HTML, измените `"module": "es6"` на `"module": "none"` или `"amd"`.*

### Шаг 4. Настройка IntelliSense для HTML
Чтобы Visual Studio понимала связи между `index.html` и вашими `.js` файлами (например, предлагала ID элементов при написании JS или показывала JS-функции при наведении в HTML), убедитесь, что в HTML-файле скрипты подключены стандартно:
```html
<script src="script1.js"></script>
<script src="script2.js"></script>
```
Visual Studio автоматически просканирует DOM и подключенные скрипты.

### Какие возможности рефакторинга и IntelliSense у вас появятся:

Как только `jsconfig.json` подхватится (может потребоваться пара секунд или перезагрузка VS), вы получите полноценный enterprise-уровень работы с кодом:

1. **Переименование (Rename):** Выделяете функцию или переменную -> нажимаете `Ctrl+R, Ctrl+R` (или F2). Visual Studio найдет все использования во всех `.js` файлах и безопасно переименует их.
2. **Поиск всех ссылок (Find All References):** `Shift+F12` покажет таблицу, где именно в проекте вызывается ваш код.
3. **Переход к определению (Go to Definition):** `F12` или `Ctrl+Click` по названию функции мгновенно перенесет в файл, где она объявлена.
4. **JSDoc:** Visual Studio обожает JSDoc. Если вы напишете над функцией комментарий вида:
   ```javascript
   /**
    * Вычисляет сумму
    * @param {number} a - Первое число
    * @param {number} b - Второе число
    * @returns {number}
    */
   function sum(a, b) { ... }
   ```
   IntelliSense будет показывать подсказки с типами и описаниями во всех местах вызова, как если бы вы писали на TypeScript или C#.
5. **Анализ ошибок:** VS будет подчеркивать красным попытки вызвать несуществующие методы или обратиться к необъявленным переменным.

### Важное замечание по установке
Если при создании проекта Node.js вы не находите этот шаблон, значит, при установке Visual Studio (через Visual Studio Installer) вы не выбрали рабочую нагрузку **"Разработка Node.js"** (Node.js development) или **"Разработка ASP.NET и веб-приложений"**. Вам нужно открыть Installer и добавить эти компоненты.
